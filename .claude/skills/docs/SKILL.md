description: Обновить страницы документации и схему пути пользователя по диффу ветки. Вызывать после изменений поведения, до закрытия задачи.
---

Задача не закрыта, пока документация не обновлена.

1. Найти затронутые области по диффу текущей ветки: `git diff --name-only main...HEAD` и незакоммиченное из `git status --short`.
2. Сопоставить области со страницами:
   - `src/video` → `docs/video-schema.md` и `docs/vocabulary.md`
   - `src/worker` → `docs/pipeline.md`
   - `src/lib` → `docs/architecture.md`
   - потоки пользователя → `docs/user-flow.md`
3. Обновить страницы.
4. Прогнать `pnpm docs:build`, исправить ошибки сборки и битые ссылки.
5. Закоммитить с префиксом `docs:`.
