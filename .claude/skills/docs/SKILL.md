---

Задача не закрыта, пока документация не обновлена. Страницы идут в тот же коммит, что и изменение, не после него.

1. Найти затронутые области по незакоммиченному диффу: `git diff --name-only HEAD` и `git status --short`.
2. Сопоставить области со страницами:
   - `src/video` → `docs/video-schema.md` и `docs/vocabulary.md`
   - `src/worker` → `docs/pipeline.md`
   - `src/lib` → `docs/architecture.md`
   - потоки пользователя → `docs/user-flow.md`
3. Обновить страницы.
4. Прогнать `pnpm docs:build`, исправить ошибки сборки и битые ссылки.
5. Добавить страницы в коммит с изменением, отдельным коммитом после него не делать. Префикс `docs:` только у коммита, где одна документация.
